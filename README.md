Этот репозиторий демонстрирует использование паттерна MVVM в WPF-приложении, которое моделирует базовую проверку состояния устройств (например, IP-камер).

Технологии:

WPF (.NET 9)

MVVM-подход (без сторонних библиотек)

ObservableCollection, ICommand, DataBinding

Цели проекта:

Закрепление архитектурного подхода MVVM

Подготовка шаблона для будущих промышленных решений

Отделение UI от логики и моделей

Что реализовано:

Интерфейс с таблицей устройств

Динамическое обновление статусов

Пример загрузки данных и работы с ViewModel

🔐 Репозиторий не содержит исходников коммерческих решений. Используется для демонстрации архитектурных приёмов и подходов.
